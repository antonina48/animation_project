## Описание проекта
Программа представляет собой графическое приложение, визуализирующее динамический поток капель дождя с возможностью регулировки параметров с помощью слайдеров. Реализована оптимизированная покадровая отрисовка с псевдотрехмерной перспективой и плавной анимацией падения в реальном времени. Архитектура проекта строго разделена на независимые слои данных, отображения и пользовательского интерфейса.

## Функциональные возможности
### Основной функционал
- Эффект трехмерности (3D): Создание ощущения глубины пространства — дальние капли имеют меньшие размеры, падают медленнее и обладают тусклым цветом, а ближние капли прорисовываются крупными, быстрыми и неоново-яркими.
- Непрерывная генерация капель: Автоматическое перерождение объектов в верхней части экрана после пересечения нижней границы.
- Плавный рендеринг: Главный цикл анимации оптимизирован под частоту обновления ~60 FPS без задержек и мерцания холста.

### Дополнительный функционал
- Интерактивная панель управления: Специальный блок виджетов, вынесенный в правую часть приложения.
- Динамическая регулировка плотности: Ползунок изменения количества капель на экране «на лету» (диапазон от 10 до 500 штук).
- Модификатор скорости: Слайдер для мгновенного ускорения или замедления физического падения капель.

### 5. Управление
- Space — пауза
- R — сброс
- **Слайдер «Плотность»** — перетаскивание мышью для увеличения/уменьшения числа капель.
- **Слайдер «Модификатор скорости»** — регулировка темпа симуляции от легкого моросящего дождя до шторма.

## Структура проекта
```text
animation_project/
├── .gitignore                  # Исключения для системы контроля версий
├── README.md                   # ФИО автора, описание проекта и инструкция
├── requirements.txt            # Файл конфигурации зависимостей
├── main.py                     # Главная точка входа в программу
└── src/                        # Исходный код приложения
    ├── __init__.py
    ├── app.py                  # Главный класс приложения (окно, цикл анимации)
    ├── models/                 # Математическая бизнес-логика
    │   ├── __init__.py
    │   └── animation_model.py  # Физическая модель капли и расчет псевдо-3D
    ├── renderers/              # Подсистема визуализации
    │   ├── __init__.py
    │   └── renderer.py         # Отрисовка графических примитивов на холсте Canvas
    └── widgets/                # Пользовательские элементы интерфейса
        ├── __init__.py
        └── controls.py         # Класс панели интерактивных слайдеров
```

**Назначение основных модулей:**
- `main.py` — запускает выполнение программы, связывая модули вместе.
- `app.py` — управляет созданием окна `tk.Tk()`, инициализацией холста и таймером обновления кадров.
- `animation_model.py` — отвечает за расчет координат, генерацию параметров глубины `z` и изменение плотности объектов.
- `renderer.py` — считывает состояния капель из модели, преобразует их в линии и красит в зависимости от удаленности капли.
- `controls.py` — обрабатывает события изменения положения ползунков и передает новые данные в модель.

## Пример использования
### Запуск программы
```bash
python main.py
```
### Работа в интерфейсе
1. После запуска открывается окно размером 800x600 пикселей с темным холстом, на котором начинается падение фиолетовых капель.
2. При перемещении верхнего ползунка "Плотность" вправо до значения `300`, на экране мгновенно генерируются дополнительные 150 капель разной глубины.
3. При перемещении нижнего ползунка "Модификатор скорости" до значения `2.0`, скорость падения всех элементов удваивается, создавая эффект ливня.
